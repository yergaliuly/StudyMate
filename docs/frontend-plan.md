# План твоей части: frontend

Код выдаётся и добавляется по шагам: точный путь → содержимое файла → проверка → коммит → PR.
Сейчас в архиве нет исходного кода: только папки и документы.

## Первый PR: `feat/frontend-setup`

Согласовать предложенный стек React + Vite + JavaScript. Подготовить зависимости и запуск.
Будущие файлы: `frontend/package.json`, lockfile, `frontend/index.html`,
`frontend/vite.config.js`, `frontend/src/main.jsx`, `frontend/src/app/App.jsx`.
Не вписывать фиктивные версии зависимостей. Установку и проверку сделать отдельным шагом.

Критерий готовности: сайт локально запускается, сборка проходит, второй участник может
повторить запуск по README. Сейчас этот критерий ещё не выполнен.

## Второй PR: `feat/ui-layout`

Будущие файлы: `src/styles/tokens.css`, `src/styles/global.css`,
`src/components/layout/Sidebar.jsx`, `Header.jsx`, `PageContainer.jsx` и их стили.
Воспроизвести утверждённое направление, а не изображение целиком как фон страницы.
Добавить состояния активного меню и мобильное открытие/закрытие навигации.

Критерий: единый каркас на компьютере и телефоне; навигация доступна с клавиатуры.

## Третий PR: `feat/dashboard-ui`

`src/pages/dashboard/DashboardPage.jsx`, `src/components/ui/Card.jsx`,
компоненты предметов по необходимости, `src/mocks/dashboard.js`.
Данные явно демонстрационные. Не показывать вымышленные проценты как реальный прогресс.
