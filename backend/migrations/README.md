# Миграции PostgreSQL

Здесь будут последовательные изменения структуры базы.
Сейчас миграций нет: сначала выбирается инструмент под backend-стек.

Каждое изменение должно воспроизводиться на новой локальной базе второго участника.
В миграции не включать реальные пароли, лекции, email студентов или дампы production.
Не менять уже применённую общую миграцию молча: добавлять новое изменение и проверять его.
