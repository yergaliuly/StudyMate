# Frontend — зона участника 1

React + Vite + JavaScript, собственный CSS. Подключены регистрация, вход,
проверка серверной сессии и выход. Реальный кабинет показывает профиль из `/auth/me`,
серверный список предметов с поиском/пагинацией, создание, просмотр, редактирование
с проверкой версии и удаление пустых предметов. При конфликте сохраняется черновик;
после потери ответа результат изменения проверяется отдельным GET. Демо открывается
явно и хранит свои предметы отдельно в браузере. Материалы пока не подключены.

Из каталога `frontend`: `npm ci`, затем `npm run dev`. Адрес интерфейса —
`http://127.0.0.1:5173`; запросы `/api` идут через Vite proxy на backend
`http://127.0.0.1:8080`. Production preview используется для тестов с подменой API;
dev proxy не является настройкой production-сервера.

Запуск и полный ручной сценарий с backend:
[проверка авторизации](docs/auth-integration-check.md).

Предметы: [методы API](docs/subject-api.md),
[ручная проверка предметов](docs/subjects-integration-check.md).

## Папки

| Путь | Назначение |
| --- | --- |
| `public/` | Статические файлы, которые станут публичными; никогда не хранить здесь лекции студентов |
| `src/app/` | Корневой компонент, маршруты и общий каркас приложения |
| `src/components/layout/` | Sidebar, Header, основной контейнер страницы |
| `src/components/ui/` | Общие кнопки, карточки, поля, диалоги, состояния загрузки |
| `src/pages/` | Страницы; каждая тематическая группа в своей папке |
| `src/styles/` | Палитра, базовые стили, сетка и адаптивность |
| `src/services/` | Работа с API; не вызывать сервер хаотично из каждого компонента |
| `src/context/` | Общее состояние пользователя после выбора схемы авторизации |
| `src/hooks/` | Повторно используемая логика React, только по необходимости |
| `src/mocks/` | Явно демонстрационные данные для разработки без backend |
| `src/utils/` | Форматирование размера файла, дат и другие небольшие функции |
| `src/assets/` | Иконки и изображения интерфейса, но не пользовательские загрузки |
| `tests/` | Node-тесты API-адаптеров и управления сессией |
| `e2e/` | Playwright-проверки интерфейса с подменёнными ответами API |

Файлы `.gitkeep` — обычные пустые файлы, чтобы подготовленные каталоги попали в Git.
Когда в каталоге появится код, соответствующий `.gitkeep` можно удалить.

Будущие названия файлов и порядок их создания: [план frontend](../docs/frontend-plan.md).
Визуальные правила: [дизайн](../docs/design.md).

## Конфигурация

В `.env.example` есть только публичный адрес API. Секретов там нет.
Любую frontend-переменную `VITE_*` нужно считать доступной посетителю сайта.
Пароли базы и ключи R2/ИИ относятся только к серверу.

Не показывайте демонстрационные проценты прогресса как реальные вычисления.
Пока формула прогресса не согласована, используйте подпись «Демо» или уберите процент.

Справка о публичности Vite-переменных: `https://vite.dev/guide/env-and-mode`.
