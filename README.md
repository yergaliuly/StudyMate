# StudyMate

**ИИ-помощник для учёбы: лекции → конспекты → тесты → результаты.**

> Статус: стартовый каркас репозитория, без реализации приложения.
> Здесь есть папки, документация, дизайн-ориентир и шаблоны командной работы.
> Сайт и сервер пока НЕ запускаются. `package.json`, зависимости и код добавим
> отдельными небольшими pull request. `npm install` и `npm run dev` пока выполнять не нужно.

![Утверждённое визуальное направление StudyMate](docs/design/studymate-reference.png)

## Команда

| Участник | Ответственность | Основная папка |
| --- | --- | --- |
| Участник 1 — выбранная пользователем роль | Интерфейс, адаптивность, формы, взаимодействие с API, проверки UI | `frontend/` |
| Участник 2 | Сервер, PostgreSQL, Cloudflare R2, обработка PDF, ИИ, безопасность | `backend/` |

Изменения контракта API и общих файлов согласуют оба участника.

## Технологии и границы решений

PostgreSQL для структурированных данных и Cloudflare R2 для файлов уже выбраны.
Для интерфейса **предлагается** React + Vite + JavaScript и собственный CSS.
Этот frontend-стек — новое предложение для каркаса, а не ранее утверждённое требование.
Конкретные версии зависимостей зафиксируем при настройке первой рабочей версии.
Язык и фреймворк сервера пока не выбраны: папка `backend/` намеренно нейтральная.

## Структура

```text
studymate/
├── frontend/            # Интерфейс: папки под страницы, компоненты, стили, API
├── backend/             # Сервер: место для реализации, миграций и тестов
├── docs/                # Архитектура, API, дизайн, план и инструкции
├── .github/             # Шаблоны задачи и pull request
├── .editorconfig        # Общие правила форматирования
├── .gitattributes       # Текстовые файлы и окончания строк
├── .gitignore           # Что не добавлять в Git
└── README.md
```

## С чего начать

Сначала откройте [инструкцию для Windows и GitHub](docs/git-setup-windows.md).
Распакуйте ZIP и отправьте в репозиторий **его содержимое**, а не ZIP одним файлом.
Откройте в VS Code папку `studymate`, где лежит этот README.
Архив не содержит `.git`, пользовательских аккаунтов, ключей и установленных библиотек.

После первой загрузки используйте [правила веток и PR](docs/git-workflow.md).
Начало разработки интерфейса описано в [плане frontend](docs/frontend-plan.md).

## Минимальная рабочая версия

Регистрация → создание предмета → загрузка PDF с извлекаемым текстом → конспект
→ тест → сохранённый результат. Чат, карточки и расширенный прогресс добавим позже.
Демонстрационные данные интерфейса будут явно отделены от настоящих результатов.

## Безопасность

Реальные `.env`, API-ключи, пароли, дампы базы и студенческие материалы не входят в Git.
В frontend нельзя помещать секреты PostgreSQL, R2 или ИИ-провайдера.
Изменения доступа к данным проверяются сервером, а не только интерфейсом.
